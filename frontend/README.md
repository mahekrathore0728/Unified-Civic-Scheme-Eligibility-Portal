# Frontend - Unified Civic Scheme & Eligibility Portal

The frontend is built with **React**, **Vite**, **React Router**, and standard CSS. It provides a clean, responsive, government-tech user interface for discovering Indian government welfare schemes, filtering programs by category and jurisdiction, and running rule-based citizen eligibility evaluations.

## Prerequisites
- Node.js (v18+)
- npm (v9+)

## Setup and Running

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Production Build:**
   ```bash
   npm run build
   ```
